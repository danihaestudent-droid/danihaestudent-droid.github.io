Política de Privacidad — Personita Curiosa

Última actualización: 21 de noviembre de 2026

1. Alcance y propósito de la aplicación

Personita Curiosa Studio es una herramienta de automatización editorial operada exclusivamente por el creador propietario del canal Personita Curiosa para renderizar, publicar y consultar estadísticas de sus propios videos educativos en YouTube Shorts, Facebook Reels y TikTok.

2. Datos accedidos mediante APIs oficiales

La aplicación únicamente solicita permisos OAuth autorizados por el propietario del canal para:

  • Google / YouTube Data API v3 y YouTube Analytics API: subir videos del canal propietario y leer métricas agregadas de reproducciones y retención.
  • Meta / Facebook Graph API: publicar Reels en la Página oficial administrada por el propietario y consultar métricas básicas de la Página.
  • TikTok Content Posting API: subir videos educativos propios y consultar el estado de publicación.

3. Uso, almacenamiento y protección de datos

No recopilamos, vendemos, alquilamos ni transferimos datos personales de terceros ni de visitantes externos. Los tokens de acceso se almacenan cifrados en variables de entorno privadas y secretos de repositorio para uso exclusivo del propietario.

El uso de información recibida de las APIs de Google cumple con la Google API Services User Data Policy, incluidos los requisitos de Uso Limitado (Limited Use).

4. Revocación de acceso y eliminación de datos

El propietario puede revocar el acceso en cualquier momento desde la configuración de seguridad de Google Account Permissions, desde la configuración de integraciones comerciales de Facebook o desde los ajustes de aplicaciones conectadas en TikTok, eliminando inmediatamente cualquier token almacenado en el entorno del estudio.
